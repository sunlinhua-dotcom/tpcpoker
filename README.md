# Titan Poker Bangkok Website

Available at: [www.titanpokerbangkok.com](http://www.titanpokerbangkok.com)

## Overview

A high-end, dynamic website for Titan Poker Bangkok, featuring premium aesthetics, glassmorphism design, and smooth animations.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: CSS Modules + Global CSS Variables (No Tailwind)
- **Icons**: Lucide React
- **Animation**: Framer Motion

## Development

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Install dependencies
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
# App will run on default port (usually 3000)
```

### Building for Production

```bash
npm run build
npm run start
# Production server runs on port 8080 (configured in package.json)
```

## Deployment

Target: Zeabur (Port 8080)
The `start` script is configured to listen on port 8080.
